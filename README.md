# Meu Jaleco Dashboard

Dashboard independente para a cliente Meu Jaleco Brasil, desenvolvido pela CoderMundi.

Tecnologias: React, TypeScript, Vite e Recharts.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Dados

A primeira versão apresenta dados fictícios explicitamente sinalizados. Nunca utilize estes valores como resultados reais. Integração GA4/WooCommerce deverá ocorrer por backend autenticado, sem credenciais no navegador.

## Design

Base branca e rosa `#F27999`, layout responsivo, filtros de datas, indicadores, gráficos e listagem de pedidos.
